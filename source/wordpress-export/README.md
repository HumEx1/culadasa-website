# WordPress export

`inspirationstation.WordPress.2026-11-20.xml` is the WordPress WXR export of culadasa.com ("Inspiration Station") made by Elizabeth Pugh on 20 November 2026 and sent to the "Culadasa website" email thread on 23 November 2026. It is a snapshot: never edit it. Inventory of its contents is in `docs/PROJECT_BRIEF.md` §6.

It contains page content, menus, Elementor data and media **URLs**. It does not contain the media files themselves; those must be downloaded from the live site.
